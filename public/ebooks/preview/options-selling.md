# 期权卖方指南


## 第一章：为什么卖 Put 是一种优势策略

期权卖方（Option Seller / Writer）在统计上占多数优势。
根据 CBOE 数据，约 55-65% 的期权在到期时变为废纸（worthless）。
这意味着卖方天然站在概率一边。

### 三种核心卖方策略

- **Cash-Secured Put（现金抵押卖 Put）**：卖出 Put 同时持有等额现金，到期若被行权则以更低价格买入股票
- **Covered Call（备兑看涨）**：持有股票同时卖出 Call，收取权利金
- **Iron Condor（铁蝶）**：同时卖出 OTM Put 和 OTM Call，构建有限风险收益的区间策略
